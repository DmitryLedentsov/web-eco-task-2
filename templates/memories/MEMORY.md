# Agent memory

- This Hermes instance is deployed only for the `web-eco-task-2` laboratory work.
- The practical goal is P1: demonstrate deployment, Telegram access control, persistent memory, a custom skill, autonomous cron execution and restart after VPS reboot.
- The research goal is T3: analyze threats and residual risks of an autonomous agent with terminal and network access.
- Runtime is intentionally isolated in Docker on a dedicated VPS.
- The agent working directory is `/workspace`.
- Never reveal API keys, bot tokens, authentication data or the contents of secret files.
